<p class="doc-subtitle">Add TOTP Two-Factor Authentication to Your Outlook Account</p>

Add an authenticator app as a sign-in method on your Microsoft account, scan the QR code with your Seedkeeper PRO App, then enter the generated code back into Microsoft to confirm.

## Overview

Microsoft accounts support authenticator apps as a two-factor authentication method. This guide walks through setting that up using your Seedkeeper PRO instead of a phone-based authenticator app. Here's what the full flow looks like:

## Step-by-Step Instructions

### Step 1: Go to Advanced Security Options

Open [Microsoft account Advanced Security Options](https://account.live.com/proofs/manage).

### Step 2: Sign in

Sign in with the Microsoft account you use for Outlook.

### Step 3: Add another way to sign in

Under your sign-in or security methods, click **Add another way to sign in to your account**.

### Step 4: Use an app

Click **Use an app**.

### Step 5: Set up a different Authenticator App

Since your Seedkeeper PRO App - not Microsoft Authenticator - will display your OTP codes, select **Set up a different Authenticator App**.

### Step 6: Scan the QR code

Microsoft displays a QR code. Scan it with the Seedkeeper PRO App - see [Adding a TOTP Account](/docs/product-documentation/otp-authenticator/adding-a-totp-account) for the full flow.

### Step 7: Enter the generated code

Type the OTP code generated by your Seedkeeper PRO into the Microsoft setup screen, then click **Next**.

Your Microsoft account is now protected by an extra layer of authentication via OTP code, generated by your Seedkeeper PRO.

## Deleting an OTP Method

Follow the same first steps: under your sign-in or security methods, find the OTP entry, then **Remove** it.

</details>

## Overview

Amazon's Two-Step Verification (2SV) supports either SMS codes or an authenticator app - the authenticator app option is the more secure of the two, since SMS can be intercepted through SIM-swapping attacks. This guide walks through setting up the authenticator app method using your Seedkeeper PRO. Here's what the full flow looks like:

## Step-by-Step Instructions

### Step 1: Sign in to Amazon

Open [amazon.com](https://www.amazon.com/) in a browser and sign in with your existing email and password.

### Step 2: Go to Login & Security

From **Your Account**, select **Login & security**.

### Step 3: Turn on Two-Step Verification

Find **2-Step Verification** and select **Turn on** (or **Edit**/**Manage** if you've started this before).

### Step 4: Choose Authenticator App

When asked how you'd like to receive your codes, choose **Authenticator App** rather than Phone Number.

### Step 5: Scan the QR code

Amazon displays a QR code. Scan it using the Seedkeeper PRO App - see [Adding a TOTP Account](/docs/product-documentation/otp-authenticator/adding-a-totp-account) for the full flow.

### Step 6: Enter the generated code

Your Seedkeeper PRO App now shows a fresh OTP code. Enter it into Amazon's confirmation field and select **Verify code and continue**.

### Step 7: Confirm

Select **Turn on Two-Step Verification** to finish.

Your Amazon account is now protected by an extra layer of authentication via OTP code, generated by your Seedkeeper PRO.

## Turning Off Two-Step Verification

From the same **Login & security** page, select **Disable** next to Two-Step Verification.

## FAQ

<details>
<summary>Do I need the Seedkeeper PRO App for this, or just my Seedkeeper PRO?</summary>

You need the Seedkeeper PRO App to scan the QR code and generate the OTP code - unlike passkeys, OTP codes always go through the app. See [Adding a TOTP Account](/docs/product-documentation/otp-authenticator/adding-a-totp-account).

</details>

<details>
<summary>What if my code expires before I enter it?</summary>

Recalculate it - see [Managing OTP Entries](/docs/product-documentation/otp-authenticator/managing-otp-entries).

</details>

<details>
<summary>Can I use both a passkey and TOTP on the same Amazon account?</summary>

Yes - see [How to Secure Amazon with a Passkey](/docs/tutorials/webshop/secure-amazon-with-a-passkey) if you'd like to set that up too.

</details>

<details>
<summary>Is an authenticator app more secure than SMS codes?</summary>

Yes. SMS-based codes can be intercepted through SIM-swapping attacks, while an authenticator app ties your codes to a physical device only you control.

</details>

Two-factor authentication requires two different kinds of evidence before granting access: something you know, such as a password, plus something you have, such as a one-time code or a hardware key. A leaked password alone is then not enough to get in. Learn more in [What is 2FA?](/docs/security-academy/authentication/what-is-2fa)

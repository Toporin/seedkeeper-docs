An Authenticator Attestation GUID identifies the make and model of a security key, not an individual unit. Organisations use it to allow only approved hardware during passkey registration. Seedkeeper PRO's AAGUID is `328dec20-698f-5d33-aed3-97daba53b1b0` - see [Device Capabilities](/docs/developers/device-capabilities).

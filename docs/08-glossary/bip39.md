BIP39 defines how a wallet converts a random number into a mnemonic phrase using a fixed 2,048-word list, and how those words become a wallet seed. The checksum it adds is what lets an app reject a mistyped phrase. Learn more in [What is BIP39?](/docs/security-academy/seed-phrases/what-is-bip39)

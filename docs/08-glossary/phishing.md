Modern phishing kits clone a login page pixel for pixel and can relay a one-time code to the real site in real time. A passkey defeats it structurally, because the credential is bound to the real domain and refuses to respond elsewhere. See [Common Password Attacks](/docs/security-academy/password-security/how-passwords-are-cracked).

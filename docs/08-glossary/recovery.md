How recovery works decides how much your security is actually worth: an account with a strong credential and a weak reset path is protected by the reset path. On a Seedkeeper, the password manager is recoverable from a Backup device, while passkeys are not - they are registered again. See [Passkey Recovery Strategy](/docs/product-documentation/passkeys/passkey-recovery-strategy).

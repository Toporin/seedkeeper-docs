## FAQ

<details>
<summary>De quelle application ai-je réellement besoin ?</summary>

Cela dépend de ce que vous voulez faire : mots de passe uniquement → la Seedkeeper App (ou la Satochip-Utils App sur ordinateur). Passkeys ou OTP en plus → ajoutez la Seedkeeper PRO App. Le [Guide de première configuration](/docs/product-documentation/getting-started/first-setup-guide) détaille tout cela.

</details>

<details>
<summary>Ces applications sont-elles open source ?</summary>

Oui. Les applications Seedkeeper sont publiées sous licence AGPLv3.

</details>

<details>
<summary>Faut-il un compte pour utiliser ces applications ?</summary>

Non. Seedkeeper ne dépend d'aucun cloud : aucun compte, aucune donnée envoyée à un serveur.

</details>

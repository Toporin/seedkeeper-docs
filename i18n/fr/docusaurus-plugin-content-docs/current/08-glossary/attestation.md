keywords: [attestation, attestation FIDO2, vérification matérielle]
sidebar_position: 3
sidebar_label: "Attestation"
---

Lors de l'enregistrement, un authentificateur peut joindre une déclaration signée indiquant ce qu'il est, afin qu'un service puisse vérifier qu'un identifiant a bien été créé sur du matériel approuvé plutôt que dans un coffre-fort logiciel. La plupart des services grand public l'ignorent ; les déploiements en entreprise s'en servent pour imposer une politique matérielle. Voir [FIDO2 Integration Guide](/docs/developers/fido2-integration-guide).

Le Client to Authenticator Protocol régit la communication entre votre navigateur et votre authentificateur. Associé à WebAuthn, qui couvre la partie entre le site web et le navigateur, il forme FIDO2. La Seedkeeper PRO implémente CTAP2.1. Voir [Qu'est-ce que FIDO2 ?](/docs/security-academy/passkeys/what-is-fido2)

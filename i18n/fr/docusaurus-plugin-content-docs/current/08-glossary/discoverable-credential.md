Un discoverable credential conserve la référence du compte sur l'appareil lui-même : le service apprend qui vous êtes à partir de l'identifiant. Les credentials non découvrables ne stockent rien sur l'appareil et exigent que vous vous identifiiez d'abord. La Seedkeeper PRO en contient jusqu'à 90. Voir [How Passkeys Work](/docs/security-academy/passkeys/how-passkeys-work).

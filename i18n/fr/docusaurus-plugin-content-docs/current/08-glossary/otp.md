Un OTP est généré à partir d'un secret partagé avec le service lors de la configuration : les deux parties calculent donc le même code sans aucun réseau. La forme courante est le TOTP, qui change toutes les trente secondes. En savoir plus dans [Qu'est-ce que l'OTP ?](/docs/security-academy/authentication/what-is-otp)

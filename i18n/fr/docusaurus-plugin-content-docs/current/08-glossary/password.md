Un mot de passe est une chaîne de caractères secrète - lettres, chiffres, symboles, ou un mélange - partagée entre vous et un service, et utilisée pour prouver votre identité lors de la connexion. Comme les deux parties le détiennent, l'une ou l'autre peut le laisser fuiter : c'est la faiblesse structurelle que les passkeys ont été conçues pour supprimer.

En savoir plus dans [What is a Password?](/docs/security-academy/password-security/what-is-a-password)

sidebar_label: "Secure Element"
---

Les clés générées à l'intérieur d'un secure element ne peuvent pas en être relues - ni par vous, ni par l'application, ni par un logiciel malveillant. Seedkeeper utilise un secure element certifié EAL6+ aussi bien pour les mots de passe que pour les passkeys et les secrets OTP.

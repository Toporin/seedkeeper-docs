Le TOTP est le standard ouvert derrière la quasi-totalité des applications d'authentification. Comme il ne nécessite aucun réseau, une Seedkeeper PRO génère les codes hors ligne. En savoir plus dans [Qu'est-ce que le TOTP ?](/docs/security-academy/authentication/what-is-totp)
